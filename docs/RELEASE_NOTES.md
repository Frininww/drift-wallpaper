Drift 1.0.0 — native video wallpapers for macOS 13 and later.

- Local MP4, MOV and M4V library with an original looping Aurora demo.
- Independent playback and automatic occlusion pause for each display.
- Pauses for display sleep, inactive sessions, serious thermal pressure and Low Power Mode.
- Optional pause on battery, aspect fill/fit, menu bar controls and opt-in launch at login.
- Native SwiftUI/AppKit interface; AVFoundation video-only playback; no third-party dependencies.

Download `Drift-universal.zip`, unzip it and move Drift to Applications.

This build is ad-hoc signed and **not notarized by Apple**. On first launch, macOS may require an explicit exception in System Settings → Privacy & Security → Open Anyway. Verify the source and checksum first. The app does not require Screen Recording or Accessibility access. See the README for build instructions, limitations and performance guidance.
