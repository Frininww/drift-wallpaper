# Drift

Нативные видеообои для macOS 13+, Apple Silicon и Intel. Основная документация — [на английском](../README.md).

[Скачать](https://github.com/Frininww/drift-wallpaper/releases/latest) · [Производительность](PERFORMANCE.md) · [Изменения](../CHANGELOG.md)

![Вкладка Wallpapers в Drift со встроенными обоями Aurora](wallpapers.png)

## Возможности

- Локальные видео MP4, MOV и M4V, которые воспроизводит macOS; рекомендуются H.264 и HEVC.
- Английский интерфейс по умолчанию. Русский включается сразу в **Settings → Appearance → Language → Русский** и сохраняется после перезапуска.
- Разрешение: Original / 1080p / 1440p / 4K. Частота: Original / 24 / 30 / 60 / 120 FPS.
- Лёгкое демо Aurora 720p / 24 FPS и отдельное демо Aurora 4K / 60 FPS.
- Независимые плееры, автоматическая пауза и выключатель для каждого экрана.
- Кадр из видео или отдельная картинка как системный фон, который macOS также может показывать при блокировке; синхронизация и восстановление прежней картинки.
- Один работающий экземпляр Drift: новые копии открывают существующее окно, старые версии завершаются перед запуском новых обоев.
- Пауза при сне экрана, неактивном сеансе, перегреве и энергосбережении; работа от аккумулятора — по настройке.
- Управление из строки меню, заполнение/вписывание видео и автозапуск по желанию.
- Только видеодорожка: звук не попадает в очередь воспроизведения. Нет аккаунтов, рекламы, аналитики, сетевых запросов или сторонних зависимостей.

## Установка

1. Скачай `Drift-universal.zip` из [Releases](https://github.com/Frininww/drift-wallpaper/releases/latest).
2. Распакуй и перенеси **Drift.app** в **Программы**. Перед заменой заверши старую версию.
3. Запусти Drift, нажми **Add video** и выбери видео; нажми на его карточку, чтобы установить обои.
4. Для русского интерфейса открой **Settings → Appearance → Language**.

Сборка имеет локальную ad-hoc подпись и не заверена Apple. При первом запуске macOS может заблокировать приложение. Проверь источник и контрольную сумму, затем разреши открытие через **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Отключать Gatekeeper целиком не нужно. Можно собрать приложение из исходников.

Для проверки архива рядом с `SHA256SUMS.txt`:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Доступ к записи экрана и универсальному доступу не требуется. Видео копируются в библиотеку Drift; исходники остаются на месте.

## Качество и FPS

**Original / Исходное** сохраняет разрешение и частоту оригинала, включая 4K и высокий FPS, если это поддерживают Mac и экран. Этот режим не добавляет видеокомпозитор и не ограничивает источник значениями 4K или 120 FPS.

Остальные значения — **верхние ограничения**. Они не создают новые детали и кадры: ролик 720p / 24 FPS останется таким даже при выборе 4K / 120 FPS. Настройки показывают фактический вывод. Соотношение сторон, ориентация и скорость воспроизведения сохраняются.

Чтобы попробовать настоящий более качественный источник, нажми **Settings → Playback quality → Add 4K / 60 FPS demo**. Русский путь: **Настройки → Качество воспроизведения → Добавить демо 4K / 60 FPS**.

Пониженные ограничения используют видеокомпозицию и могут добавлять нагрузку. Для экономии энергии лучше короткий, эффективно закодированный ролик. Фиксированных обещаний расхода CPU, памяти или батареи нет; методика проверки — в [PERFORMANCE.md](PERFORMANCE.md).

## Управление

| Действие | Где |
| --- | --- |
| Выбрать обои | Нажать карточку коллекции |
| Пауза / продолжить | Кнопка обложки или строка меню |
| Изменить язык | Settings → Appearance → Language |
| Разрешение и FPS | Settings → Playback quality |
| Масштаб и экраны | Settings → Display |
| Автозапуск | Settings → Startup |
| Удалить видео | Правый клик по карточке |
| Вернуть системные обои | Turn wallpapers off |
| Полностью остановить | Строка меню → Quit Drift |

Закрытие окна оставляет приложение в строке меню. После завершения Drift видна текущая системная картинка, в том числе установленная через функцию фона.

## Экран блокировки и системная картинка

Открой **Settings → Lock Screen & system background** (по-русски — **Настройки → Экран блокировки и системный фон**). Можно выбрать момент видео ползунком и применить кадр либо выбрать отдельную картинку. Меняется системный фон текущих рабочих пространств на подключённых экранах; macOS также может использовать его при блокировке.

Это **статичная общая системная картинка**, а не независимый живой Lock Screen. Она меняет и фон рабочего стола под Drift. Экран входа, FileVault, системные aerial и отображение при блокировке остаются под управлением macOS. Приложение не меняет loginwindow и системные видео и не отключает защиту.

Синхронизация первого кадра при переключении обоев по умолчанию выключена. Кнопка восстановления отключает синхронизацию и возвращает прежнюю картинку, где это возможно. Более новая картинка, выбранная вне Drift, не перезаписывается. Восстановление картинки не восстанавливает режим динамических обоев, aerial или слайд-шоу; для них есть кнопка системных настроек.

Своих запросов подтверждения для этих действий Drift не добавляет. Обязательные диалоги доверия и выбора файлов macOS остаются системными.

## Сборка

Нужны Xcode 16+, инструменты командной строки и Swift 6+. Внешних пакетов нет.

```sh
git clone https://github.com/Frininww/drift-wallpaper.git
cd drift-wallpaper
swift test
bash scripts/build-app.sh --universal
open dist/Drift.app
```

Для разработки открой `Package.swift` в Xcode. Без `--universal` собирается только текущая архитектура. Для Developer ID используй переменную `SIGNING_IDENTITY`; заверение Apple выполняется отдельно и требует собственного Apple Developer аккаунта.

## Данные и ограничения

Данные лежат в `~/Library/Application Support/Drift/`: настройки и список видео — в `library.json`, копии видео — в `Wallpapers/`. Запись атомарная, старые библиотеки версии 1.0 мигрируют с сохранением выбора и настроек. Повреждённый манифест сохраняется в резервную копию.

Произвольное видео на защищённом экране блокировки и собственная заставка не поддерживаются. GIF, сайты, потоки, DRM и проекты Wallpaper Engine не поддерживаются. Прозрачные окна, Spaces и Stage Manager могут влиять на определение видимости. Пауза сохраняет кадр и ресурсы плеера; для освобождения выключи обои или заверши Drift.

Шаблоны автосборки лежат в [workflows/](workflows/). Для включения перенеси их в `.github/workflows/` и отправь через подключение с правом `workflow`; до этого автоматизация не активна.
